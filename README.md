# Sistema de Gerenciamento Financeiro Pessoal

Projeto acadêmico desenvolvido com foco em organização financeira pessoal, apresentando interface responsiva para desktop (PC) e dispositivos móveis (celular).

## Funcionalidades
- Controle de entradas, saídas e acompanhamento da sobra/saldo mensal.
- Organização de categorias e lançamentos financeiros.
- Layout responsivo adaptado para telas largas (PC).

## Como visualizar / testar
1. Faça o download ou clone este repositório.
2. Abra os arquivos do projeto no editor ou abra o arquivo principal (`index.html`) no navegador (ou inicie o servidor local do projeto, conforme a estrutura).
3. Para testar o modo celular no navegador do PC, abra as ferramentas de desenvolvedor (`F12`) e ative a visualização responsiva/mobile, ou redimensione a janela.

## Contexto do projeto
Desenvolvido para fins acadêmicos e demonstração de portfólio no GitHub.
